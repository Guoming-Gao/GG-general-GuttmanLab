# SPEN CLAP-to-Input ratio versus expression

This package builds the authoritative artifact-assessment report for the
expression-dependent SPEN CLAP-to-Input ratio. It reuses validated endogenous
No-Dox SPEN matrices and untreated total-RNA counts, separates normalized CLAP
and Input coverage, tests pseudocount and Input-depth sensitivity, and processes
HnRNPC, PTBP1, and GFP HUHCLAP controls without modifying their source data.

The earlier volcano-bin, treatment-response, metagene, expression-matching, and
Dox/Xist analyses remain available as provenance under `prior_exploration/`, but
they are not regenerated by the default workflow.

  --snakefile metagene_analysis/workflow/Snakefile \

`report/SPEN_expression_dependence_report.html`

## Current interpretation

The primary quantity is named explicitly throughout:

`log₂[(TMM-normalized CLAP + pseudocount)/(TMM-normalized Input + pseudocount)]`

Untreated total-RNA abundance is an independent expression measurement for the
mouse SPEN analysis. In all introns, expression correlates with CLAP coverage
(ρ=0.84) and even more strongly with Input coverage (ρ=0.90), while the
CLAP-to-Input ratio is inversely correlated (ρ=−0.50). This favors a substantial
denominator/coverage component. The association weakens but persists after
minimum-Input filters and pseudocount changes.

CA calls are not a primary validation because zeros dominate and peak-detection
power is strongly expression-dependent. Zero-dominated plots were deleted. The
retained CA figures condition on at least one called window and therefore test
peak multiplicity only; zero fractions are retained solely as QC. HUHCLAP uses
matched Input as its only expression proxy, so those control ratios are
mathematically coupled diagnostics rather than independent confirmation.

## Output guide

- `report/`: the sole authoritative self-contained report.
- `results/01_CLAP_to_Input_ratio/`: untreated-expression tertile discovery
  figures and exact plotted data.
- `results/02_CA_peak_validation/`: peak-positive CA sensitivity figures,
  exact counts, zero-fraction QC, and conditional length analyses.
- `results/03_Input_expression_check/`: CLAP numerator, Input denominator,
  ratio, pseudocount, and coverage-filter diagnostics.
- `results/04_HUHCLAP_controls/`: HnRNPC, PTBP1, and GFP results.
- `results/05_CA_vs_EBS_method_choice/`: endogenous No-Dox method-yield audit.
- `supporting_data/`: validated reused matrices, annotations, HUHCLAP caches,
  normalized tables, pooled BAM derivatives, and CA outputs.
- `workflow_records/`: logs, checksums, rename audit, and read-only source
  verification.
- `prior_exploration/`: superseded volcano, directional, matched-expression,
  Dox/Xist, metagene, and prior-report artifacts.

## Validation

```bash
conda run -n bioinfo pytest -q metagene_analysis/tests
conda run -n bioinfo snakemake \
  --snakefile metagene_analysis/workflow/Snakefile \
  --configfile metagene_analysis/config/config.yaml \
  --cores 1 --dry-run
```

The HUHCLAP source directory is treated as read-only and full SHA-256 hashes are
compared before and after execution. Bootstrap seed is `20260812`; the 100
resamples provide exploratory uncertainty intervals.
